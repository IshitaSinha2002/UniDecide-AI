<h1>UniDecide AI</h1>

<p>
  An AI-powered University Selection Committee built using LangChain and LangGraph.
</p>

<h2>About</h2>

<p>
  UniDecide AI is an LLM-based university selection system that helps compare
  universities from multiple perspectives before arriving at a final recommendation.
</p>

<p>
  The system uses multiple AI advisors, where each advisor evaluates the universities
  from a different perspective. Their individual opinions are then passed to a
  Final Committee agent, which analyzes all perspectives and produces the final
  recommendation.
</p>

<h2>Tech Stack</h2>

<ul>
  <li><strong>Python</strong></li>
  <li><strong>LangChain</strong></li>
  <li><strong>LangGraph</strong></li>
  <li><strong>Groq</strong></li>
  <li><strong>Llama 3.3 70B Versatile</strong></li>
</ul>

<h2>How It Works</h2>

<p>
  The user provides a university comparison such as:
</p>

<pre>
MIT vs Stanford vs CMU for AI
</pre>

<p>
  The input is passed into a LangGraph workflow containing multiple advisor nodes.
</p>

<h3>1. Academic Advisor</h3>

<p>
  Evaluates the universities from an academic perspective, including:
</p>

<ul>
  <li>Curriculum strength</li>
  <li>Course flexibility</li>
  <li>Faculty quality</li>
  <li>Academic rigor</li>
  <li>AI/ML coursework</li>
  <li>Interdisciplinary opportunities</li>
  <li>Overall academic environment</li>
</ul>

<h3>2. Career Advisor</h3>

<p>
  Evaluates the universities based on career-related factors such as:
</p>

<ul>
  <li>Career opportunities</li>
  <li>Industry connections</li>
  <li>Internships</li>
  <li>Recruiting opportunities</li>
  <li>Startup opportunities</li>
  <li>Location advantages</li>
  <li>Long-term career value</li>
</ul>

<h3>3. Financial Advisor</h3>

<p>
  Evaluates the financial aspects of attending each university, including:
</p>

<ul>
  <li>Tuition and overall cost</li>
  <li>Cost of living</li>
  <li>Financial aid</li>
  <li>Scholarships</li>
  <li>Return on investment</li>
  <li>Career earnings potential</li>
  <li>Opportunity cost</li>
</ul>

<h3>4. Research Advisor</h3>

<p>
  Evaluates the universities specifically from an AI and research perspective.
</p>

<ul>
  <li>AI/ML research strength</li>
  <li>Research opportunities</li>
  <li>Faculty research ecosystem</li>
  <li>Research laboratories</li>
  <li>Research culture</li>
  <li>Opportunities to work with professors</li>
  <li>Graduate research pathways</li>
  <li>Emerging AI research areas</li>
</ul>

<h3>5. Student Life Advisor</h3>

<p>
  Evaluates the overall student experience.
</p>

<ul>
  <li>Campus culture</li>
  <li>Student community</li>
  <li>Clubs and organizations</li>
  <li>Diversity</li>
  <li>Social environment</li>
  <li>Location and lifestyle</li>
  <li>Work-life balance</li>
</ul>

<h3>6. Alumni Perspective</h3>

<p>
  Evaluates the long-term value of the universities from an alumni perspective.
</p>

<ul>
  <li>Alumni network</li>
  <li>Professional connections</li>
  <li>Brand reputation</li>
  <li>Career mobility</li>
  <li>Networking opportunities</li>
  <li>Entrepreneurial ecosystem</li>
  <li>Long-term value of the university community</li>
</ul>

<h3>7. Final Committee</h3>

<p>
  The Final Committee receives the opinions generated by all six advisors.
  It then evaluates the different perspectives, identifies disagreements,
  weighs the arguments, and selects one final university.
</p>

<p>
  The final response includes:
</p>

<ul>
  <li>Final recommendation</li>
  <li>Why the university wins</li>
  <li>Committee analysis</li>
  <li>Strongest alternative</li>
  <li>Final verdict</li>
</ul>

<h2>Implementation Steps</h2>

<h3>Step 1: Set Up the LLM</h3>

<p>
  The project uses Groq with the Llama 3.3 70B Versatile model.
  The Groq API key is stored in a <code>.env</code> file and loaded using
  <code>python-dotenv</code>.
</p>

<h3>Step 2: Define the Shared State</h3>

<p>
  A <code>UniversityState</code> TypedDict was created to maintain the information
  shared between the LangGraph nodes.
</p>

<p>
  The state contains the user's query, universities, individual advisor opinions,
  and the final committee decision.
</p>

<h3>Step 3: Create the Advisor Agents</h3>

<p>
  Separate Python files were created for each advisor. Each advisor uses
  LangChain's <code>ChatPromptTemplate</code> to create a specialized prompt
  for its particular perspective.
</p>

<h3>Step 4: Create the Final Committee</h3>

<p>
  A separate Final Committee agent was created. It receives the outputs of all
  six advisors and synthesizes them into a final recommendation.
</p>

<h3>Step 5: Build the LangGraph</h3>

<p>
  The advisor functions were added as nodes in a LangGraph state graph.
  The six advisors receive the initial state and their outputs are collected
  before the Final Committee runs.
</p>

<h3>Step 6: Connect the Workflow</h3>

<p>
  The graph was connected using START and END nodes. The six advisors feed their
  analysis into the Final Committee, which produces the final decision.
</p>

<h3>Step 7: Run the Application</h3>

<p>
  The application is executed through <code>main.py</code>. The user enters a
  university comparison, and the resulting advisor opinions and final committee
  recommendation are displayed in the terminal.
</p>

<h2>Example</h2>

<h2>Key Concept</h2>

<p>
  The main idea behind the project is to use multiple specialized LLM perspectives
  instead of relying on a single prompt to make the university recommendation.
  LangGraph is used to orchestrate these perspectives and pass their outputs to
  a final decision-making node.
</p>
